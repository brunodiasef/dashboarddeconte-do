Nova aula — gerar cadastro

Como publicar para todos os dispositivos:
1. Envie o arquivo HTML da aula para a pasta aulas/ do repositório.
2. No GitHub, abra o arquivo apresentacoes.js e clique no lápis (editar).
3. Cole o código acima dentro da lista, antes do ]; (separe por vírgula se já houver outra aula).
4. Clique em Commit changes. Pronto: a aula aparece no painel em qualquer dispositivo.

O cadastro é feito no arquivo apresentacoes.js do repositório, por isso a aula fica visível em todos os dispositivos.

Como cadastrar

1

Envie o arquivo da aula para o repositório

No GitHub, abra o repositório do projeto e envie o arquivo HTML da aula para a pasta aulas/ (botão Add file → Upload files).

2

Clique em Nova aula no painel

Preencha título, ano, trimestre, número da aula, descrição e o nome do arquivo enviado.

3

Copie o código gerado

O painel monta o registro pronto da aula. Clique em Copiar código do cadastro.

4

Cole no arquivo apresentacoes.js

No GitHub, abra apresentacoes.js, clique no lápis para editar e cole o código dentro da lista, antes do ];. Se já houver outras aulas, separe cada uma por vírgula.

5

Faça o commit

Clique em Commit changes. A aula passa a aparecer no painel em qualquer dispositivo, pois os dados ficam no próprio repositório.
